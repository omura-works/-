# コード生成ショーリール

撮影素材・画像・音源・3D モデルを一切使わず、**映像の全ピクセルと音声の全サンプルをコードから計算する** 60 秒の動画 (1920×1080 / 30fps / ステレオ 48kHz) です。

| 章 | 内容 | 技術 |
|---|---|---|
| 00 | 粒子がタイトルの形に収束 | Canvas 2D・18,000 粒子 |
| 01 | 3D フラクタル (マンデルバルブ) | GLSL レイマーチング・ソフトシャドウ・AO |
| 02 | 反応拡散 (Gray-Scott) | WebGL2 浮動小数テクスチャでの GPU シミュレーション |
| 03 | 迷路の生成と最短経路 | 深さ優先生成 → 幅優先探索 |
| 04 | ストレンジアトラクタ | 毎フレーム 320 万回の反復を密度として描画 |
| 05 | エンディング | このリポジトリ自身のソースを背景に実数値を表示 |

音楽 (`audio.py`) も numpy だけで波形を合成しています (加算合成パッド、プラック、キック、ノイズ由来のハイハット、畳み込みリバーブ)。

## 作り方

必要なもの: Node.js、Playwright + Chromium、ffmpeg、Python 3 + numpy

```bash
cd showreel
npm install
TITLE="タイトル" npm run build      # → out/showreel.mp4
```

| 環境変数 | 意味 | 既定値 |
|---|---|---|
| `TITLE` | イントロとエンディングに出すタイトル | `SHOWREEL` |
| `CREDIT` | エンディング最下行の小さなクレジット | なし |
| `NAME` | 出力ファイル名 | `showreel.mp4` |
| `JOBS` | 並列に動かすブラウザ数 | `4` |
| `AA` | フラクタルのアンチエイリアス (1 画素あたりのサンプル数) | `2` |
| `ONLY` | 指定した章だけ描き直す (例 `ONLY=maze,outro`) | 全章 |

確認用に 1 フレームだけ出すこともできます。

```bash
node render.cjs still bulb 120 out/bulb.png
```

## 仕組み

- `src/scenes/*.js` — 各章。`frame(ctx, i, t)` がフレーム番号から絵を決定的に描く
- `render.cjs` — ヘッドレス Chromium でフレームを 1 枚ずつ描画し、ffmpeg (libx264) へパイプ。章を分割して並列化し、最後に無劣化で連結して音声を多重化
- `audio.py` — 100 BPM・25 小節。映像の章立て (3+4+4+4+4+6 小節) と小節単位で同期

GPU がない環境でも SwiftShader (ソフトウェア WebGL) で動きます。全編のレンダリングは 4 コアで 10 分前後です。
