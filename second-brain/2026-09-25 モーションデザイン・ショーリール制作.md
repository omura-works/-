## 依頼（プロンプト原文）

## 構成（128BPM・1小節＝1.875秒）
| 時間 | シーン | 内容 |
|---|---|---|
| 0.0s | IGNITION | 点が縮んで溜める → 線に伸びる → 「MOTION design」 → 画面が裂けるグリッチ |
| 1.9s | TYPE | 拍ごとに「EVERY / SINGLE / FRAME / matters.」 |
| 3.8s | FORM | 斜めのカラー帯で転換 → 円・四角・三角・星に形が変わる＋色の残像 |
| 5.6s | PARTICLES | 粒子が爆発して「FLOW」になり、渦に吸い込まれる |
| 7.5s | DEPTH | 3D：球 → ドーナツ型 → 立方体 → 波打つ面 |
| 9.4s | TIMING | 高速パン → 動きの緩急を示すグラフ画面 |
| 11.3s | SYSTEMS | 円形に広がる転換 → 12個のループ → 1マスにズーム |
| 13.1s | FINALE | 衝撃音 → 「CLAUDE.」（冒頭の点がピリオドとして戻る） |

- 配色：黒 `#0A0A0C`／ライム `#C8FF2E`／コーラル `#FF4A1C`／バイオレット `#6C4DFF`／生成り `#F4EFE6`
- 書体：Inter Tight 900、Instrument Serif Italic、JetBrains Mono、Noto Sans JP
- 仕上げ：ビートに合わせた画面の揺れ・色ずれ・フィルムの粒子感・周辺減光、動きのブラー

## 手順（実際にかかった時間：約30分）
1. 環境を確認（ffmpeg・ブラウザ・フォント）
2. 絵コンテ：1小節を1シーンにして、8シーンを設計
3. 映像（`reel.js`）と音（`audio.js`）を書く
4. コマ一覧で目視確認 → ずれを修正
5. 本番の書き出し（約9分）→ 画質を少し落として軽くする
6. commit・push → 下書き PR → 動画を送る

## ハマった点と対処
- [ ] **ffmpeg がない** → pip の `imageio-ffmpeg` で対応（今は `setup.sh` が自動でやる）
- [ ] **画面が336pxずれて切れる** → キャプチャ時に `.wrap` の余白を消す CSS を追加
- [ ] **36MB と重い** → `-crf 22 -maxrate 12M` で約10.5MB
- [ ] **書き出し待ちの間に停止フックで止められる** → ソースだけ先に commit・push する

## 確認したこと／していないこと
- ✅ 900フレームをコマ一覧と原寸で目視確認
- ✅ 音量：平均 −11dB、ピーク −0.8dB（音割れなし）
- ⚠️ 動画を実際に再生したり、音を耳で聴いたりはしていない
