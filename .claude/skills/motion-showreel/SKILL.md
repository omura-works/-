# モーショングラフィックス動画の作り方（第2の脳）

このリポジトリの `showreel/` は、完成済みの制作パイプラインのテンプレートです（15秒・1920×1080・60fps・128BPM、音付き）。
ゼロから作らず、ここをコピーして作り変えます。説明と提案はすべて日本語で、提案は常に複数案を出します。

## すぐ使えるプロンプト

```
/motion-showreel 【尺】秒の【用途：履歴書用ショーリール / 自己紹介 / 商品紹介 / SNS縦型 など】を作って。
名前: 【表示する名前】 / キャッチコピー: 【任意】 / 雰囲気: 【例: ダーク×ネオン、パステル、モノクロ】
サイズ: 【1920x1080 / 1080x1920 / 1080x1080】 / BPM: 【任意、既定128】
```

情報が足りなくても止まらずに、既定値（15秒・16:9・ダーク×ライム・128BPM）で作ります。最後に改良案を複数出します。

## 手順（この順番で進める。合計で約20分）

1. **準備（1分）**：`eval "$(showreel/tools/setup.sh)"` を実行する。libx264 対応の ffmpeg を用意し、`$FFMPEG` を設定する。
2. **複製**：`cp -r showreel <新しいフォルダ名>` で作業フォルダを作り、以降はその中で作業する（元のテンプレートは残す）。
3. **絵コンテ**：1小節（60/BPM×4 秒）を1シーンにする。15秒・128BPM なら8シーン。
   各シーンは「入り → 拍ごとの変化 → 次のシーンへの転換」で設計し、転換の方法は毎回変える（カット、斜めワイプ、形が画面を覆う、渦で吸い込む、ウィップパン、アイリス、ズームイン）。
   最後は最初のモチーフに戻す（例：冒頭の点がロゴのピリオドになる）。
4. **映像** `reel.js`：
   - `SCENES[i](ctx, t)` を書き換える。すべての描画は時間 `t` だけで決める（乱数は `mulberry32` の固定シードを使う）。
   - 時間の制御は `prog(t,a,b)`、イージングの `E.*`、`spring()`、`pulse()` を使う。
   - 転換は `compose()` に、ヒット（画面の揺れ・色ずれ）は `HITS` に、章の名前は `CHAPTERS` に書く。
   - 文字は `letters()`（1文字ずつ動かせる）、`scramble()`（デコード風）、`fitSize()`（幅に合わせる）を使う。
5. **音** `audio.js`：`CHORDS`・`PROG` と、`build()` の中の配置（arrangement）を書き換える。キック・クラップ・ハイハット・ベース・パッド・プラック・ベル・ウーッシュ・ライザー・インパクト・グリッチが用意されている。場面転換と同じ秒数に効果音を置く。
6. **確認（毎回必ずやる）**：
   - `node tools/preview.mjs /tmp/pv --every 0.5` でコマ一覧を作り、Read で目視する。
   - 気になる秒は `node tools/preview.mjs /tmp/pv 9.38 13.3` のように指定して、原寸で確認する。
7. **本番の書き出し（約9分）**：`node render.mjs --mb 4 --workers 4 --out <名前>.mp4` を `run_in_background` で実行し、進み具合は Monitor で見る。
   音の確認：`$FFMPEG -i x.wav -af volumedetect -f null -` で平均 −10〜−13dB、ピーク −1dB 前後なら良い。
8. **納品**：SendUserFile で mp4 と contact-sheet.png を送り（display: render）、commit・push して、下書きの PR を作る。

## 学んだこと（同じ失敗を繰り返さない）

- **ffmpeg**：システムに入っていない。Playwright に付属の ffmpeg は VP8 しか使えないので、pip の `imageio-ffmpeg` を使う（setup.sh が自動で対応）。
- **フォント**：Google Fonts から woff2 を落として、同じフォルダに置く（`fonts.css`）。file:// では読み込めないので、render.mjs は内蔵の http サーバーから配信している。和文は `text=` パラメータで、使う文字だけのサブセットにする。
- **キャプチャ時のずれ**：`?capture=1` のとき、`.wrap` の余白をなくす CSS が必須。これがないと、画面が 336px ずれて切れる。
- **ファイルサイズ**：グレインが入っていると、CRF16 で 36MB になった。`-crf 22 -maxrate 12M` にすると約10MB で、見た目はほぼ同じ。
- **速度**：モーションブラー4枚なら約0.55秒/フレーム（4並列）。確認中は `--mb 1`、または preview.mjs を使う。
- **停止フックの対策**：書き出しの待ち時間中に、先にソースだけ commit・push しておく。

## 改良案の出し方（毎回、3〜4案を出す）

名前や連絡先の差し替え ／ 縦型（9:16）・正方形（1:1）版 ／ 30秒への延長（実績の紹介シーン）／ 配色や曲調の変更 ／ 各シーンを長く見せるテンポ調整
